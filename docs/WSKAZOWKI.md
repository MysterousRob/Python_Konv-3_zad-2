# Wskazówki

- `sum(lista)` oblicza sumę liczb, `len(lista)` ich liczbę.
- Przed dzieleniem sprawdź, czy lista nie jest pusta.
- Funkcja `oblicz_srednia` powinna **zwracać** liczbę, a nie ją drukować.
- Zbuduj słownik podsumowania z trzema wymaganymi kluczami.
- Importuj funkcje z pozostałych modułów, zamiast powielać logikę.
- Podczas diagnozowania testów uruchom pojedynczy plik, np. `python -m pytest tests/test_utils.py -v`.
- Komunikat `NotImplementedError` wskazuje miejsce, w którym trzeba napisać kod.
